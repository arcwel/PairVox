# PairVox 0.1.0-beta.1

The first public build of PairVox, a voice front-end for Claude Code on the Mac with a companion iPhone app. You talk, Claude Code works in your project, and its replies are read back as they stream. Talk over it to interrupt. Answer permission requests by voice, with a click, or on the phone.

This is a beta. It works every day on the author's Mac. Three of the five v0.1 checks have not been measured yet (a timed headset session, spoken approvals on the Mac, and saying "Allow" on the phone), so expect rough edges.

## What's in it

**Mac app**
- Hands-free listening, or hold ⌃⌥Space to talk. Speech recognition (WhisperKit, with Apple Speech as the fallback) and the voice (Kokoro, with the system voice as the fallback) run on the Mac.
- Barge-in: start talking and PairVox stops speaking. Talk while Claude works and the turn is redirected.
- Full, Skip code and Summary reading modes. Brainstorm runs Claude Code in plan mode, and Execute lets it make changes.
- Requests read as one line ("Claude wants to edit streaks dot py. Allow?"). High-risk steps, such as deleting files, pushing, `sudo`, edits outside the project or printing the environment, always need a click.
- Several projects at once, folder-level approvals and cross-project approvals.
- A health indicator in the toolbar with a one-click fix for each part that needs attention.
- PairVox, Install Latest Build… updates a build made from your own checkout.

**iPhone app**
- Pairs with the Mac over Tailscale by QR code or a pasted link.
- Shows the active project's conversation and speaks replies in the Mac's voice.
- Approve with a tap and Face ID, or by voice for requests the Mac allows by voice.
- A request that arrives while the app is in the background shows a lock-screen notification. Allow appears there only for a short, ordinary request.

## Install

**Mac.** Download `PairVox-0.1.0-beta.1.dmg` and drag PairVox to Applications. It is ad-hoc signed and not notarized, so macOS blocks the first launch. Open it once, then go to System Settings, Privacy & Security, click **Open Anyway** next to PairVox, and open it again. You need macOS 15 or later on Apple Silicon, and Claude Code installed and signed in (`claude`, then `/login`).

**iPhone.** `PairVoxPhone-0.1.0-beta.1-unsigned.ipa` is not signed. Install it with AltStore or Sideloadly, which sign it with your own Apple ID. Or build it from source (see `ios/README.md`). With a free Apple ID the app opens for 7 days before it needs reinstalling. You need iOS 18 or later and Tailscale on the phone and the Mac.

A notarized Mac build and a TestFlight build both need a paid Apple Developer account, which this project does not have yet.

## Security

- **Code audit (run 8).** Covers everything since the v0.1 gates (`ac00462..de91222`). It found five leads, and all five are fixed with regression tests in this build. None let a high-risk request be approved by voice.
- **Strix.** The penetration test ran on the release code with Gemini, a model from a different family than the one that wrote the code. It found nothing at any severity across 18 areas. Its own record lists what it did not examine: argument injection and business logic, and a live attack on the phone link.
- **Gitleaks.** A scan of the full git history found no secrets.

The Strix report is attached as `PairVox-0.1.0-beta.1-strix-report.md`. `PairVox-0.1.0-beta.1-security-reports.zip` holds the full Strix output and the run 8 audit report with its findings. They are also in the repository under `docs/security/`.

## Privacy

There is no telemetry. Audio stays on the Mac or the phone, and only text crosses the phone link. PairVox never reads or stores Claude credentials. It runs your own `claude` command, which uses its own login.

## Known limits

- The Mac build is not notarized, and the iPhone build is not signed (see Install).
- The phone link has not been fuzzed or attacked live.
- The phone's Face ID claim is reported by the phone itself, so a modified phone could approve what an unmodified one could approve with a tap.
- No in-app updates for downloaded builds yet. Install Latest Build… works only for a build made from a checkout.
